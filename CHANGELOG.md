# История настройки рабочего места

Фиксируем только подтверждённые этапы, чтобы не забывать, что и зачем менялось.

## 2026-11-09 — реорганизация репозитория

- Перенесены исходные файлы учебного `vscode-web-lab` в `examples/vscode-web-lab/` без потери содержимого.
- Добавлены README, шпаргалка, инструкция восстановления, безопасность, документация VS Code / Git / Zsh и примеры конфигураций.
- Добавлен минимальный `Brewfile` из реально установленных для этой работы инструментов.
- Шаблоны настроек и сниппетов отмечены как восстановленные по диалогу, **не как проверенный экспорт локальных файлов**.

## Ноябрь 2026 — выполнено на Mac

- VS Code: создан профиль `Web Development` с Prettier, ESLint, EditorConfig, GitLens, vscode-icons; настроены сохранение/форматирование и ручной запуск ESLint через Task и `Ctrl + Option + L`.
- JavaScript lab: `.prettierrc.json`, `eslint.config.mjs` (Flat Config), `.editorconfig`, npm-скрипты; проверены ошибки `no-unused-vars` и `no-undef` и автоформатирование.
- Git: 10 собственных Git-алиасов, `init.defaultBranch=main`, `core.editor=code --wait`.
- Zsh: интерактивные комментарии, история, автоподсказки, подсветка синтаксиса, fzf, zoxide, сокращения Git, справа текущая Git-ветка.
- VS Code Shell Integration: подтверждён режим «Расширенная».
- Node: установлен `fnm`, версия `22.21.0` назначена по умолчанию, подготовлен `.node-version`.
- AI: проверены Codex CLI, установлен `OpenAI.chatgpt` для профиля; пользователь сообщил, что подсказки работают. Шаблон `AGENTS.md` **не применялся** по решению пользователя.
