# Шпаргалка: VS Code, Git, Zsh, Node

Короткая памятка, которую удобно закрепить вкладкой в VS Code. **В первый день используй только 5–6 самых полезных команд; остальное подключай по мере надобности.**

## Каждый день

| Команда / клавиши (macOS) | Что делает |
| --- | --- |
| `gs` | Git-статус (сокращение для `git st`) |
| `gl` | Граф последних 20 коммитов |
| `ga file.js` | Добавить файл в staging |
| `gc -m "feat: ..."` | Создать коммит |
| `z часть-имени` | Перейти в посещённую папку через zoxide |
| `Ctrl + R` | FZF: поиск по истории команд |
| `Cmd + P` | Быстро открыть файл в VS Code |
| `Ctrl + Option + L` | Запустить задачу `Quality: ESLint` в текущем проекте |

## Git: короткие команды

| Сокращение | Полная команда / смысл |
| --- | --- |
| `git st` / `gs` | `git status --short --branch` |
| `git br` / `gb` | `git branch` |
| `git sw main` / `gsw main` | `git switch main` |
| `git new feature/header` | `git switch -c feature/header` |
| `git lg` / `gl` | `git log --graph --oneline --decorate --all -20` |
| `git last` | `git log -1 --stat` |
| `git df` / `gd` | `git diff` (неиндексированные изменения) |
| `git ds` / `gds` | `git diff --staged` |
| `git unstage file.js` | `git restore --staged file.js` — сохранить изменения, убрать из staging |
| `git ci -m "message"` / `gc -m "message"` | `git commit -m "message"` |
| `git root` | Показать корень Git-репозитория |
| `g` | `git` |

**Осторожно:** `git new` создаёт ветку; `git sw` переключает, а не создаёт. Не добавляй алиасы для `reset --hard`, `clean -fd` и принудительного push — их лучше писать явно.

## Zsh / навигация

| Команда / клавиши | Результат |
| --- | --- |
| `..`, `...`, `....` | На 1, 2 или 3 папки выше |
| `z vscode-web-lab` | Переход к знакомой директории |
| `Ctrl + R` | Поиск в истории через fzf |
| `Ctrl + T` | Выбрать файл через fzf |
| `Alt + C` | Выбрать директорию через fzf (нужна корректная передача Option/Alt терминалом) |
| `→` | Принять серую подсказку из истории |
| `source ~/.zshrc` | Перечитать интерактивные настройки |
| `zsh -n ~/.zshrc` | Проверить синтаксис конфигурации |

Примеры `.zshrc` и `.zprofile` см. в [shell/](shell/). История команд может содержать чувствительные данные — не публикуй её.

## Node.js / fnm

| Команда | Значение |
| --- | --- |
| `fnm list` | Установленные версии |
| `fnm current` | Текущая версия |
| `fnm install 22.21.0` | Установить конкретную версию |
| `fnm use 22.21.0` | Выбрать версию для текущей сессии |
| `fnm default 22.21.0` | Версия по умолчанию |
| `node --version` | Версия Node |
| `node -p "process.execPath"` | Фактически запущенный исполняемый файл |
| `npm ci` | Установить зависимости строго по lock-файлу |

Для автопереключения создай в проекте `.node-version` с нужной версией и перейди в его папку; в `.zshrc` используется `fnm env --use-on-cd`.

## Качество кода и задачи

| Команда | Действие |
| --- | --- |
| `npm run lint` | ESLint: проверить код |
| `npm run lint:fix` | ESLint: исправить поддерживаемые проблемы |
| `npm run format` | Prettier: записать форматирование |
| `npm run format:check` | Prettier: проверить без изменения файлов |
| `Cmd + Shift + P` → `Tasks: Run Task` | Запуск задачи редактора |
| `Cmd + S` | Сохранить и запустить форматирование, если оно включено для файла |

**Важно:** такие npm-скрипты есть в нашем [тестовом примере](examples/vscode-web-lab/); в произвольном проекте они могут называться иначе или отсутствовать. `Ctrl + Option + L` запускает задачу с точным именем `Quality: ESLint`, если она определена в рабочей области.

## VS Code: горячие клавиши и сниппеты

| Клавиши / сокращение | Результат |
| --- | --- |
| `Cmd + Shift + P` | Палитра команд |
| `Cmd + Shift + F` | Поиск по проекту |
| `Cmd + D` | Следующее совпадение |
| `Cmd + Shift + L` | Все совпадения |
| `F12` | Перейти к определению |
| `Shift + F12` | Найти использования |
| `Cmd + .` | Quick Fix |
| `Option + Shift + F` | Форматировать документ |
| `Ctrl + Backtick` | Показать / скрыть терминал |
| `clg` | Сниппет `console.log()` |
| `afn` | Сниппет `async function` |
| `rcomp` | Сниппет React-компонента, только JSX/TSX |

`clg` и `afn` проверены в редакторе. Сниппеты вызываются по префиксу и выбираются в подсказках; `Ctrl + Space` вызывает подсказки вручную.

## Если что-то не работает

- ESLint не подсвечивает, но CLI проверяет? `ESLint: Restart ESLint Server`, затем панель `Problems` и канал `Output → ESLint`.
- Prettier не срабатывает? Проверь `.prettierrc.json`, `prettier.requireConfig` и доверие к рабочей области.
- `z` / алиасы отсутствуют? Открой **новый терминал** или `source ~/.zshrc`.
- `which node` показывает системный Node? Сверь `node -p "process.execPath"`, `fnm current` и PATH в новом терминале.
- `npm audit` сообщает об уязвимостях? Не запускай `--force` без анализа отчёта.
