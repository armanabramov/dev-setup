# Безопасность публичного репозитория

`dev-setup` — **публичный** репозиторий. Здесь должны находиться только проверенные для публикации документы, шаблоны и учебный код.

## Не публиковать

- API-ключи, токены, cookies, пароли, SSH-ключи, содержимое `.env`, `.npmrc` с токенами, доступы к GitHub / OpenAI / БД.
- Реальные пользовательские конфиги без проверки, в особенности `~/.codex/config.toml`, `~/.zsh_history`, `~/.ssh`, `~/.npmrc`.
- Клиентские данные, содержимое коммерческих проектов, локальные пути к приватным папкам или дампы баз данных.

`.gitignore` защищает только от **неотслеживаемых** файлов. Он не удаляет секреты, уже попавшие в Git-историю.

## Безопасная проверка перед push

```bash
git status --short
git diff
git diff --cached
```

Посмотри каждый новый файл, особенно конфигурации и экспорт профиля. Если секрет уже попал в опубликованную историю, одного удаления файла недостаточно: сначала отзови/поменяй секрет, затем разберись с очисткой истории.

## Текущий статус

- Файлы с суффиксом `.example` — **санитизированные образцы**, не слепые копии реальной системы.
- Секреты Codex, токены GitHub и файлы `~/.codex` сюда не добавлялись.
- GitHub Settings Sync VS Code и Git-репозиторий — разные механизмы хранения.
